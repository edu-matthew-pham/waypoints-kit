# Sorting Organisms into Kingdoms

**Name:** {{field-24}} **Date:** {{field-15}} **Class:** {{field-15}}

> **Key question:** How can we place living things into kingdoms using only what we can observe, and how do we justify our choice?

A pencil case is sorted by what you can *see*: pens with pens, rubbers with rubbers. Scientists sort living things the same way, by observable features, not by guesses, habits or "it just looks like one". [teacher: swap in your own analogy from the slides if you prefer.]

:::teacher-note

**Waypoint 2 (hinge).** Students who can't reliably assign organisms to kingdoms using observable features can't choose discriminating features when they build keys in waypoint 4. Watch for justifications that aren't features, such as "it lives in the ground", "it's small", "it's dangerous" or "I just know". A mushroom placed with the plants is the classic error.

Assumes five kingdoms (Animals, Plants, Fungi, Protists, Bacteria). [teacher: change if your school uses a different set.] Organisms are shown on image cards. [teacher: attach or project a card for each organism, with a number on each. Microscopic organisms need a micrograph.]

:::

:::teacher-note

**Euglena:** a protist. It has chloroplasts and makes food like a plant but swims and can feed like an animal. **Virus:** not placed in any kingdom. It is not made of cells, and scientists still debate whether it is alive. A good answer says the model has edges, without claiming the model is wrong.

**Levels:** each level groups organisms by shared features, becoming more specific from kingdom to species. Accept any sensible description of how a level narrows the group.
