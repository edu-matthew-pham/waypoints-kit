# Where each file comes from

Snapshot as of Oct 2026. "Copied" means the wording is taken from the source with small neutral edits; "reconstructed" means written for this kit from the source's ideas, not copied. If a kit file and its source differ, the source is right, with one exception: since 10 Nov 2026 the node files in `data/` are the master copy. Fix them here, not in Progressions; Progressions can later show the kit's data once it's settled.
