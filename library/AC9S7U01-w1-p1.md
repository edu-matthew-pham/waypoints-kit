<!-- _class: vocab -->
<!-- _header: '**Concept** What is classification?' -->

:::: grid-2x1

> **Classification:** Organising living things into groups based on the features they share. It is done for a reason: so people can find, name and talk about living things.
>
> **Biodiversity:** All the variety of living things on Earth: animals, plants, fungi, bacteria and every other type of organism, not only the animals we see most.

> **KEY VOCABULARY**
>
> **classify** — to put things into groups using a system and a purpose
>
> **organism** — one living thing
>
> **system** — a set of rules for how to organise something

::::

<!-- Speaker note: [MINIMUM] Misconception to catch (node glossary): biodiversity means 'lots of animals'. Give examples across plants, fungi and microscopic organisms. Do not name the kingdoms yet: that is waypoint 2. -->

<!-- _header: '**Concept** Why do scientists classify?' -->

Scientists classify living things for three main reasons:

| Reason | What it lets us do |
|---|---|
| **Identify** | Work out what an unknown organism is |
| **Communicate** | Use the same names and groups so everyone means the same thing |
| **Study** | Compare groups and look for patterns across many organisms |

<!-- Speaker note: [MINIMUM] The minimum is two reasons. Identify and communicate come straight from the node file's examples; study is from the student glossary. Ask students to say each reason in their own words before moving on. -->

<!-- _class: compare callout-navy -->
<!-- _header: '**I Do: Worked Ex. 1** Sorting or classifying?' -->

:::: grid-2x1

> **SORTING: laundry by colour**
>
> - Groups by one surface feature
> - No system behind it
> - Purpose: it just looks tidy

> **CLASSIFYING: a library**
>
> - Uses a system: subject, author, title
> - Everyone uses the same rules
> - Purpose: anyone can find a book they have never seen

::::

> Classification has a SYSTEM and a PURPOSE: it helps people find, name and talk about things.

<!-- Speaker note: [MINIMUM] Model the thinking aloud. Ask: what would break if a library was organised by cover colour? Students should say they could not find a book by topic. This addresses the node file's 'does not confuse classification with simple sorting' criterion. -->

**"Biodiversity includes plants, fungi and bacteria as well as animals."**

> **✓ TRUE**
>
> **Why?** Biodiversity is the variety of all living things, so it includes every type of organism, not only animals. A place with few animals can still have high biodiversity.

<!-- Speaker note: [MINIMUM] This checks the biodiversity misconception from the node glossary (narrow repertoire: animals only) from the other side: the true statement. Some of the true or false checks in this library are true on purpose, so students cannot just vote false. -->

<!-- _header: '**Concept** Two systems, the same animals' -->

Two ways to classify the same six animals:

| Animal | System A: where it lives | System B: body covering |
|---|---|---|
| Kangaroo | Grassland and woodland | Fur |
| Koala | Eucalypt forest | Fur |
| Magpie | Open woodland and gardens | Feathers |
| Emu | Open plains and woodland | Feathers |
| Blue-tongue lizard | Woodland, grassland and gardens | Scales |
| Green tree frog | Near water and in trees | Smooth, moist skin |
