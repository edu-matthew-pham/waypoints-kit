<!-- _header: '**Concept** If you see... think...' -->

The same table, read the other way round:

| If you see... | Think... |
|---|---|
| Green, fixed, with leaves | Plants |
| Takes in food and usually moves | Animals |
| Fuzzy threads or a cap and stalk, not green, on its food | Fungi |
| A single cell you need a microscope to see | Protists (or bacteria if very small) |
| Tiny rods or spheres, only visible at high power | Bacteria |

<!-- _header: '**Check** ✓ Answer' -->

**"Any green organism must be a plant."**

> **✗ FALSE**
>
> **Why?** Green is not enough. Some moulds look green, and some single cells are green. Plants are also fixed in place and have leaves, stems or roots, so use more than one feature.

<!-- Speaker note: [MINIMUM] The point for a hinge waypoint: a single feature can mislead. Reliable placement uses several observable features. -->

<!-- _header: '**Concept** The Linnaean hierarchy' -->

Groups sit inside bigger groups. As you go down, groups get smaller and their members share more features.

| Level | Example: human |
|---|---|
| Kingdom | Animalia |
| Phylum | Chordata |
| Class | Mammalia |
| Order | Primates |
| Family | Hominidae |
| Genus | Homo |
| Species | sapiens |

<!-- Speaker note: [WIDER: can drop] Wider width, from the node file: classify using the Linnaean hierarchy (kingdom to species) and explain what each level represents. Misconception (node glossary): memorising the levels as a list. Ask what happens to the number of shared features as you go down. A nested boxes model helps. -->

<!-- _header: '**Discuss** Boundary cases' -->

> Euglena is a single cell that can make its own food using light, like a plant, and swim, like an animal. Viruses are not made of cells, and scientists debate whether they are living. **Do they fit the kingdom model? What does the difficulty show about the rules of our system?**
