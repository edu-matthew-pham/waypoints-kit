<!-- _header: '**Concept** A new key: Key C, leaves' -->

Key C identifies five types of leaf. Same two-choice logic, different organisms.

| Step | (a) If the organism… | (b) If the organism… |
|---|---|---|
| **1** | is divided into many small leaflets on one stalk → **Fern frond** | is one piece → go to 2 |
| **2** | is thin and stiff like a needle → **Pine needle** | has a flat blade → go to 3 |
| **3** | has veins running side by side → **Grass blade** | has veins in a branching net → go to 4 |
| **4** | has a smooth edge → **Gum leaf** | has small jagged teeth on the edge → **Jagged-edged leaf** |

**Which decision point would break a key?**

- **A** Has 8 legs, or does not have 8 legs
- **B** Has a coiled shell, or has no coiled shell
- **C** **Is big, or is small**
- **D** Veins side by side, or veins in a branching net

Key B identifies the same six garden animals as Key A, but asks the questions in a different order.

| Step | (a) If the organism… | (b) If the organism… |
|---|---|---|

<!-- _header: '**Evaluate** ✓ Key D: the error' -->

| Question | Model answer |
|---|---|
| **Error** | Step 1 offers 'has a coiled shell' or 'has legs'. These are not opposites. |
| **Consequence** | The earthworm and the slug have no coiled shell and no legs, so they fit neither option and the key dead-ends. |
| **Correction** | Change 1(b) to 'has no coiled shell' and add the steps for legless animals, as in Key A. |
