# Glossaries

Pre-built vocabulary for some subjects. Fetch at `https://acara.learningwaypoints.com/data/<path>`. Each file has `teacher_glossary` (definition, likely misconception, response) and `student_glossary` (plain definition, example). Filter entries by `descriptor_code`; `first_waypoint` says where a term first appears.

If a standard's code isn't listed under any file below, there is no pre-built glossary for it: draft one from the node file.
